## 2. README 项目简介

### 中文

**英语听写练习** 是一个面向学生的在线单词听写工具。无需安装，打开网页即可使用：

1. 上传一张包含英语单词的图片（如课本单词表、手抄单词）；
2. 应用通过 OCR 自动识别图中的英文单词；
3. 逐个播放单词发音；
4. 在输入框中拼写听到的单词，即时判断对错；
5. 练习结束后展示正确率、错词列表，并支持错题重练。

界面简洁、移动端适配，适合课堂练习或课后复习。

### English

**English Dictation Practice** is a student-friendly online vocabulary dictation tool. No installation required — just open the page:

1. Upload an image containing English words (textbook word list, handwritten notes, etc.);
2. The app auto-recognizes words via OCR;
3. Plays each word aloud;
4. Type what you hear and get instant feedback;
5. View accuracy and review misspelled words after practice.

Clean UI, mobile-responsive, perfect for classroom drills or self-study.
